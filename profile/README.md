### AI desk for DeFi

Explore markets, swap assets, and manage positions across DeFi. You set the intent. Your wallet controls the action.

- **Chat first.** Ask for a market, a swap or a position in plain language and get a concrete, reviewable action back.
- **Your wallet signs.** eziee prepares transactions; nothing moves until you approve it in your own wallet.
- **Protocols join over MCP.** Each integration is an MCP server with a reviewed manifest, so what the agent can do is explicit.
