# .github

Organization profile and shared community files for [eziee-ai](https://github.com/eziee-ai).

- `profile/README.md` is shown on the organization page.
- `profile/eziee-mark.svg`, `profile/eziee-avatar.png` and the `eziee-wordmark-*.svg` files are the brand mark. The glyphs are outlined from Satoshi Black Italic, so they render the same without the font installed. Colors come from `packages/ui/src/tokens.css` in the app repo: lime `#D7F43B`, ink `#111310`, chalk `#F3F4ED`.
